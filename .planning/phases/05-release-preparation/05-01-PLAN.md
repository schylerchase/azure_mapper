  <action>
    **R4.5 - Fix lazy bundle deployment:**
    1. In build-web.js, after line 31 (`fs.copyFileSync('dist/app-core.js', ...)`), add two new lines:
       ```javascript
       fs.copyFileSync('dist/demo-data.bundle.js', path.join(OUT, 'dist/demo-data.bundle.js'));
       fs.copyFileSync('dist/iac-generator.bundle.js', path.join(OUT, 'dist/iac-generator.bundle.js'));
       ```

    **R4.5 - Add immutable cache headers:**
    2. In vercel.json, add a new entry as the FIRST item in the `headers` array (before the catch-all `/(.*)`):
       ```json
       {
         "source": "/dist/(.*)\\.js",
         "headers": [
           { "key": "Cache-Control", "value": "public, max-age=31536000, immutable" }
         ]
       }
       ```
       This is correct because build.js injects MD5 content hashes into index.html script tags (`app.bundle.js?v=682b29b6`), so the `immutable` directive prevents revalidation of unchanged bundles. The more-specific route must precede the catch-all to take effect.

    **Verify the build output:**
    3. Run `npm run build:web` and verify `public/dist/` contains exactly 4 JS files: app.bundle.js, app-core.js, demo-data.bundle.js, iac-generator.bundle.js.
  </action>
  <verify>

  </verify>

**Change 1: Update gateway label collision resolution (around line 1769-1786)**

The current code at lines 1781-1784 only uses `shift-y`:
```js
if(gwLabelRecs.length>1){
  gwLabelRecs.sort((a,b)=>a.y-b.y||a.x-b.x);
  _resolveCollisions(gwLabelRecs,{strategy:'shift-y',padding:3});
  _applyLabelPositions(gwLabelRecs);
}
```

Replace with a two-pass approach that first tries shift-y, then applies shift-x for any remaining overlaps:
```js
if(gwLabelRecs.length>1){
  gwLabelRecs.sort((a,b)=>a.y-b.y||a.x-b.x);
  // Pass 1: vertical shift (resolves stacked labels)
  _resolveCollisions(gwLabelRecs,{strategy:'shift-y',padding:3,maxIter:4});
  // Pass 2: horizontal shift for remaining overlaps (resolves side-by-side labels)
  _resolveCollisions(gwLabelRecs,{strategy:'shift-x',padding:4,maxIter:4});
  _applyLabelPositions(gwLabelRecs);
}
```

**Change 2: Fix _applyLabelPositions for horizontal shift (around line 39-50)**

The current `_applyLabelPositions` function handles x position for text based on textAnchor, but doesn't update the text x when the rect x shifts. The textNode.attr('x', tx) line already computes `tx = textAnchor === 'middle' ? l.x + l.w / 2 : l.x + (l.textPadX || 0)` which correctly recomputes text position from the label's new x. This is already correct -- no change needed here.

**Change 3: Update the post-render cross-type collision sweep (around line 2419-2436)**

The current Phase 2 cross-type sweep only shifts down (vertical). Add a horizontal shift fallback when labels are at approximately the same Y level but overlapping horizontally. Update the inner loop (lines 2425-2435):

Replace the existing overlap handling:
```js
if(_rectsOverlap(a,b,2)){
  // Shift down if vertically overlapping
  const overlapY=(a.y+a.h+4)-b.y;
  if(overlapY>0){b.y+=overlapY;b.textNode.attr('y',b.y+b.h)}
}
```

With combined vertical+horizontal resolution:
```js
if(_rectsOverlap(a,b,2)){
  const overlapY=(a.y+a.h+4)-b.y;
  const overlapX=(a.x+a.w+4)-b.x;
  // Prefer vertical shift; use horizontal shift when labels are at similar Y
  if(overlapY>0 && overlapY<=overlapX){
    b.y+=overlapY;b.textNode.attr('y',b.y+b.h);
  } else if(overlapX>0){
    b.x+=overlapX;b.textNode.attr('x',b.x+(b.w||0)/2);
  }
}
```

This means: if labels overlap, shift in the dimension that requires the smaller displacement. For side-by-side gateways at the same Y level, overlapY will be large (full height) while overlapX will be small (just the overlap), so horizontal shift wins.
